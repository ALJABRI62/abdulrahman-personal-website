# Abdulrahman Personal Website

This project is a responsive personal/consultation website for Abdulrahman Abdulaziz Aljabri.

## How to run locally

Open `index.html` directly in a browser or run:

```bash
python3 -m http.server 8000
```

Then visit:

- http://localhost:8000
- http://localhost:8000/admin.html

## Included features

- Modern Arabic homepage
- About, services, experience, articles, and contact sections
- Responsive design for mobile and desktop
- Admin dashboard with local content management via browser localStorage
- Customizable colors and settings
